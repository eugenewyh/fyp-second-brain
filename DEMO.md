# Differentiator demo (vs ChatGPT / Claude / Grok)

**Product:** **Nous** (Greek: mind / intellect)  
**Product goal:** Private lifelong knowledge is the foundation; multi-agent research is the engine; reports are one output that *writes back* into memory.

**Tagline:** Research that remembers *you*.

---

## 30-second script

1. **Open Knowledge panel** (☰ or “Your knowledge”)  
   - Show documents added once. Say: *“This is local memory — not a chat attachment.”*

2. **Ask (composer)**  
   - Question grounded in *your* notes; the answer appears as unbubbled markdown in the same thread.  
   - Point at source chips (library / web).

3. **Agent (composer)**  
   - State a goal in the boxed prompt.  
   - Narrate muted status lines (Planner → Retriever → Verifier → Synthesizer).  
   - If plan review is on: approve / edit the plan inline.  
   - Findings appear on the canvas. Click a `[n]` citation to open the source.

4. **Write-back punchline**  
   - **Remembered in this chat** → Details shows claims / chat memory / project.md.  
   - **Open report** → the saved vault note.  
   - Show it under **Past research** in the knowledge panel / Artifacts.

5. **Continue in the same chat**  
   - Click a **deepen** chip under the answer (fills the composer; edit and send).  
   - *“Claude doesn’t keep this private corpus + self-critique + write-back by default.”*

6. **Close**  
   - Differentiation = **lifelong local memory + architectural self-critique + hybrid personal-first retrieval**, not “we can also search the web.”

---

## What not to demo first

- Generic web-only questions with empty library  
- Treating the app as “chat like ChatGPT”  
- IDE/file-manager tours without the memory loop  
- Pipeline graphs or a separate “mission view”

---

## Examiner one-liner

> Flagship chat AIs are general assistants. **Nous** is a **local-first mind for your knowledge**: knowledge you own, multi-agent research that uses it, and results that update it over time.
